### 2a. Security assessment

Fixed scope, report and remediation plan.

- Active Directory health (PingCastle-style scoring and hardening plan).
- Microsoft Entra / M365 configuration review (Maester-style automated checks + manual review).
- Identity & access review: MFA coverage, conditional access, privileged accounts.
- Cloudflare / network edge configuration.
- Endpoint & patching posture.
- Deliverable: prioritised findings, risk rating, concrete remediation steps you can hand to any IT provider.

### 2b. Penetration test

Scoped, with rules of engagement, retest included.

- External perimeter, web application, internal / Active Directory.
- Deliverable: executive summary + technical report + retest of fixed findings.
- Penetration tests are delivered under a formal engagement framework with rules of engagement and insurance in place.
